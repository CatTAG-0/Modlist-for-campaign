# Modlist for campaign
Use to sort mods from the [Campaign mod collection](https://steamcommunity.com/sharedfiles/filedetails/?id=3811254756) in Barotrauma

[![image](https://cdn2.steamgriddb.com/icon/6c6d15562b486b1d1256f567ffb6fd11.ico)](https://store.steampowered.com/app/602960/Barotrauma/)

## How to use
1. Download the latest version of campaign.xml
   * [Download Here](https://github.com/CatTAG-0/Modlist-for-campaign/releases)

2. Open the Barotrauma game directory
   * **Default Location:**
     * Press `Win + R`
     * Paste `C:\Program Files (x86)\Steam\steamapps\common\Barotrauma` and press **Enter**
   * **Find Location (If installed on another drive):**
     * Open Steam $\rightarrow$ Library $\rightarrow$ `Right-Click` **Barotrauma** $\rightarrow$ **Manage** $\rightarrow$ **Browse local files**

> [!TIP]
> If you don't have a `ModLists` folder, create a new folder and rename it to `ModLists`

3. Paste campaign.xml into the `ModLists` folder
